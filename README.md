# Network Security Risk Mitigation

## Objective
Analyze common vulnerabilities in a network infrastructure and apply basic protection, segmentation, and assurance mechanisms using controlled Docker environments to understand risks and security best practices.

## General Architecture
- Docker network `lab6-net`
- Services: MySQL, Nginx, REST API (FastAPI), Redis
- Admin container (netshoot) for reconnaissance and testing
